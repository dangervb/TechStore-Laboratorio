# TechStore-Laboratorio

Proyecto educativo de Desarrollo de Software V — Universidad Tecnológica de Panamá, Centro Regional de Colón.

## Contenido
- `index.html`: estructura HTML.
- `css/estilos.css`: diseño adaptable, modo claro y oscuro.
- `js/app.js`: catálogo, buscador, filtro, carrito, formulario y localStorage.
- `imagenes/`: cinco ilustraciones SVG provisionales (no son las fotografías PNG originales de la guía).

## Ejecución
Abrir `index.html` en un navegador o usar Live Server en VS Code. Para probar el carrito, agregar productos, modificar cantidades y recargar con F5. El formulario simula compras, no procesa pagos.

## Git y GitHub

```bash
git clone https://github.com/dangervb/TechStore-Laboratorio.git
cd TechStore-Laboratorio
git status

```

## Observación
Se mantiene la funcionalidad didáctica del taller. Las imágenes SVG son ilustraciones provisionales; para reproducir fielmente el material docente deben reemplazarse por las cinco imágenes PNG originales.
